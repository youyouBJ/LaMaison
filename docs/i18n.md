# Internationalisation — La Maison

## Architecture

L'i18n est géré via un système custom React Context, sans dépendance externe.

```
src/i18n/
  types.ts    — types (Locale, TranslationKey, Translations, TranslateFn)
  fr.ts       — dictionnaire français (source de vérité, as const)
  en.ts       — dictionnaire anglais (implémente Translations)
  index.ts    — I18nProvider, useI18n(), t()
```

### Types clés

```typescript
// TranslationKey = union de toutes les clés (dérivé de typeof fr)
type TranslationKey = keyof typeof fr;

// Translations = shape plate (chaque valeur est une string)
type Translations = Record<TranslationKey, string>;

// TranslateFn = signature de t()
type TranslateFn = (key: TranslationKey, params?: Record<string, string | number>) => string;
```

### Fonctionnement

- `fr.ts` utilise `as const` pour figer les types littéraux → TypeScript détecte les clés manquantes.
- `en.ts` implémente `Translations` (shape seulement, valeurs libres).
- La locale est persistée dans AsyncStorage (`@lamaison/locale`), **locale par appareil**, pas en base.
- Locale par défaut : `fr`.
- Fallback : locale courante → français → clé brute.

### Interpolation

```typescript
t('ma_cle', { nom: 'Youssef', couverts: 3 })
// fr.ts : 'Bonjour {nom}, table pour {couverts}'
// → 'Bonjour Youssef, table pour 3'
```

## Ajouter une nouvelle clé

1. Ajouter la clé + valeur dans `fr.ts` (source de vérité).
2. Ajouter la même clé + traduction dans `en.ts`.
3. TypeScript indiquera une erreur si une clé est manquante dans `en.ts`.
4. Utiliser `t('ma_cle')` dans le composant.

## Sélecteur de langue

Le sélecteur est dans **Paramètres → Langue de l'application** (`AdminSettingsScreen`).

```typescript
const { locale, setLocale } = useI18n();
setLocale('en'); // persiste en AsyncStorage
```

## Conventions

- Préfixe par écran : `dashboard_*`, `res_*`, `resd_*`, `floor_*`, `wl_*`, `guests_*`, `admin_*`, `settings_*`, `reminder_*`.
- Communs (partagés) : `common_*`, `status_*`, `wl_status_*`, `action_*`.
- Les feedbacks UI (ex. "WhatsApp ouvert", "Email ouvert") sont traduits — seul le contenu des messages ne l'est pas.
